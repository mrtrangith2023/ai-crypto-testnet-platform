# AI Crypto Testnet Platform

AI-powered crypto testnet farming and analytics platform built with FastAPI and Python.

---

## Features

- Wallet Tracking
- Airdrop Project Management
- AI Project Scoring
- Testnet Farming Checklist
- Funding Analysis
- Ecosystem Tracking
- Risk Detection
- REST API with FastAPI
- Swagger Documentation

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-crypto-testnet-platform.git
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run FastAPI Server

```bash
uvicorn app.main:app --reload
```
